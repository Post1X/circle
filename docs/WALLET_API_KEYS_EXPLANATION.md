# API ключи для работы с кошельками

## Краткий ответ

**Для подключения кошельков (wallet-connect) НЕ нужны API ключи от самих кошельков!**

Подключение происходит через Web3 API браузера, а бэкенд только проверяет криптографическую подпись.

---

## Детальное объяснение

### 1. Подключение кошельков (wallet-connect) - БЕЗ API ключей

**Как это работает:**

1. **Клиентская часть (браузер):**
   - Пользователь подключает кошелек через расширение браузера (TronLink, MetaMask, Phantom)
   - Кошелек предоставляет Web3 API через `window.tronWeb`, `window.ethereum`, `window.solana`
   - Пользователь подписывает сообщение своим приватным ключом (все происходит локально в браузере)
   - Подпись отправляется на бэкенд

2. **Серверная часть (бэкенд):**
   - Бэкенд получает: адрес кошелька, подпись, сообщение
   - Бэкенд **криптографически проверяет** подпись, используя публичный адрес
   - Если подпись валидна - кошелек привязывается к пользователю

**Важно:** 
- Приватный ключ НИКОГДА не покидает браузер пользователя
- Бэкенд НЕ имеет доступа к кошельку пользователя
- API ключи от кошельков НЕ нужны

**Пример проверки подписи на бэкенде:**
```typescript
// Для Tron
const recoveredAddress = tronWeb.address.fromHex(
  tronWeb.trx.verifyMessage(messageHex, signature)
);
// Если recoveredAddress === address - подпись валидна

// Для Ethereum
const recoveredAddress = ethers.utils.recoverAddress(
  ethers.utils.hashMessage(message), 
  signature
);
// Если recoveredAddress === address - подпись валидна
```

### 2. Работа с блокчейнами - НУЖНЫ API ключи

**Для мониторинга транзакций и отправки транзакций с бэкенда нужны API ключи от блокчейн-провайдеров:**

#### Tron блокчейн - TRON_API_KEY

**Где используется:**
- `TronMonitorService` - мониторинг депозитов USDT
- `WithdrawalProcessorService` - отправка USDT при выводе средств

**Как получить:**
1. Зарегистрируйтесь на https://www.trongrid.io/
2. Создайте API ключ в разделе "API Keys"
3. Добавьте в `.env`:
   ```
   TRON_API_KEY=ваш-ключ-здесь
   ```

**Бесплатный план:**
- TronGrid предоставляет бесплатный план
- Для продакшена может потребоваться платный план при больших нагрузках

**Пример использования:**
```typescript
const headers = {
  'TRON-PRO-API-KEY': this.configService.tronApiKey,
  'Content-Type': 'application/json',
};

// Мониторинг транзакций
const response = await axios.get(
  `https://api.trongrid.io/v1/accounts/${address}/transactions/trc20`,
  { headers }
);

// Отправка транзакции
const response = await axios.post(
  'https://api.trongrid.io/wallet/createtransaction',
  transactionData,
  { headers }
);
```

#### Solana блокчейн - SOLANA_RPC_URL (опционально)

**Если нужно мониторить транзакции Solana или отправлять транзакции с бэкенда:**

1. Используйте публичные RPC endpoints (бесплатно, но с лимитами):
   ```
   https://api.mainnet-beta.solana.com
   ```

2. Или используйте платные RPC провайдеры:
   - QuickNode: https://www.quicknode.com/
   - Alchemy: https://www.alchemy.com/
   - Helius: https://www.helius.dev/

**Добавьте в `.env`:**
```
SOLANA_RPC_URL=https://api.mainnet-beta.solana.com
```

#### Ethereum/BSC/Polygon - RPC_URL (опционально)

**Если нужно мониторить транзакции или отправлять транзакции с бэкенда:**

1. Используйте публичные RPC endpoints (бесплатно, но с лимитами):
   ```
   ETHEREUM_RPC_URL=https://eth-mainnet.g.alchemy.com/v2/YOUR-API-KEY
   BSC_RPC_URL=https://bsc-dataseed.binance.org/
   POLYGON_RPC_URL=https://polygon-rpc.com/
   ```

2. Или используйте платные RPC провайдеры:
   - Alchemy: https://www.alchemy.com/
   - Infura: https://www.infura.io/
   - QuickNode: https://www.quicknode.com/

## Итого: что нужно для работы

### Обязательно (уже есть в проекте):
- ✅ `TRON_API_KEY` - для мониторинга депозитов и отправки USDT
- ✅ `MNEMONIC` - для генерации адресов депозитов
- ✅ `ENCRYPTION_KEY` - для шифрования приватных ключей hot wallet

### Не нужно:
- ❌ API ключи от TronLink, MetaMask, Phantom - не нужны
- ❌ API ключи от кошельков пользователей - не нужны

### Опционально (если нужно мониторить другие блокчейны):
- ⚠️ `SOLANA_RPC_URL` - если нужно мониторить Solana транзакции
- ⚠️ `ETHEREUM_RPC_URL` - если нужно мониторить Ethereum транзакции
- ⚠️ `BSC_RPC_URL` - если нужно мониторить BSC транзакции

## Схема работы

```
┌─────────────┐
│   Браузер   │
│  (Клиент)   │
└──────┬──────┘
       │
       │ 1. Подключает кошелек (TronLink/MetaMask/Phantom)
       │ 2. Получает nonce с бэкенда
       │ 3. Подписывает сообщение (локально в браузере)
       │ 4. Отправляет подпись на бэкенд
       │
       ▼
┌─────────────┐
│   Бэкенд    │
│  (Сервер)   │
└──────┬──────┘
       │
       │ 1. Проверяет подпись криптографически
       │ 2. Привязывает кошелек к пользователю
       │ 3. Возвращает access_token
       │
       ▼
┌─────────────┐
│  Блокчейн   │
│  (TronGrid) │
└─────────────┘
       │
       │ Используется только для:
       │ - Мониторинга транзакций (TRON_API_KEY)
       │ - Отправки транзакций (TRON_API_KEY)
       │
       │ НЕ используется для подключения кошельков!
```

## Безопасность

1. **Приватные ключи пользователей:**
   - Хранятся только в браузере пользователя
   - Никогда не отправляются на сервер
   - Бэкенд работает только с публичными адресами

2. **Приватные ключи системы:**
   - Hot wallet приватный ключ шифруется в БД
   - Используется только для отправки USDT при выводе
   - Генерируется из MNEMONIC

3. **API ключи:**
   - `TRON_API_KEY` - хранится в `.env`, не коммитится в Git
   - Используется только для работы с TronGrid API
   - Не дает доступа к кошелькам пользователей

## Резюме

**Для подключения кошельков:**
- ✅ Все делается на стороне бэкенда (проверка подписи)
- ✅ НЕ нужны API ключи от кошельков
- ✅ Пользователь подключает кошелек через браузерное расширение

**Для работы с блокчейнами:**
- ⚠️ Нужен `TRON_API_KEY` от TronGrid (для мониторинга и отправки транзакций)
- ⚠️ Опционально нужны RPC URL для других блокчейнов (если нужно мониторить)
